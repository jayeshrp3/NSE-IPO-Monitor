# NSE IPO Monitoring \& Deadline Alert System

## Project Overview

The NSE IPO Monitoring \& Deadline Alert System is designed to help users monitor Initial Public Offerings (IPOs) and track important IPO-related dates and deadlines.

The project is divided into two parts:

### Part 1A : IPO Deadline Tracker

A deterministic application that manages IPO information, tracks important dates, calculates remaining days and generates deadline alerts.

### Part 1B : AI-Powered IPO Announcement Assistant

An AI-based application that extracts important IPO information from announcements, identifies deadlines and generates summaries.

## Technologies

* Python
* FastAPI
* SQLite
* HTML, CSS and Bootstrap
* GitHub Spec Kit
* Pytest

## Project Objectives

1. Simplify IPO deadline monitoring.
2. Track important IPO-related dates.
3. Generate timely deadline alerts.
4. Use AI to extract information from IPO announcements.
5. Validate application behaviour using automated harnesses.

## Development Methodology

The project follows Specification-Driven Development
using GitHub Spec Kit.

A project constitution establishes the engineering
principles, coding standards, data integrity rules,
security requirements and testing expectations.

Implementation will follow the approved specification,
technical plan and development tasks.
